# 双十一装机价格监测

自托管的商品价格监测应用，适合为 CPU、显卡、主板、内存、硬盘等电脑配件建立观察列表。界面使用中文，采集数据和价格历史保存到本地 SQLite 数据库。

## 开始使用

需要 Python 3.12+ 和 [uv](https://docs.astral.sh/uv/)。在仓库目录运行：

```bash
bash scripts/install.sh
bash scripts/start.sh
```

服务默认仅监听本机 8000 端口。在自己的电脑运行时，用浏览器访问本机的该端口即可。云环境中先按照环境的访问方式使用；本项目不包含公网部署或账号认证。

添加明确的商品链接，填写货币和目标价，选择检查间隔。首次添加会立即检查，随后在服务运行期间按设定间隔采集。达到目标价会在页面显示提醒。暂停只停止定时检查，仍可手动刷新。

## 价格的含义

- 自动读取商品页面的 JSON-LD `Product/Offer`、价格 meta 或 `itemprop` 数据。也可指定 CSS 价格选择器。
- 监测页面公开展示的商品报价。运费、优惠券、会员价、以旧换新、地区补贴与最终结算价，只有在页面明确展示且被选中的价格字段中体现时才会计入。
- 多个不同商品或多个不同报价会要求指定选择器，避免把推荐商品或其他规格的价格混入。`AggregateOffer` 的最低报价会在自动商品名中标记“最低报价”。
- 页面货币与设定货币不符会显示错误，不换算或比较不同货币。失败时保留历史报价，但撤销当前的目标价提示。
- 登录、验证码或仅由 JavaScript 动态生成的价格可能无法读取。此时记录采集失败，具体平台需要接入其允许使用的接口或适配方式。
- 这里的价格历史从成功采集时开始积累，不代表此前历史最低价；页面不会预填虚构商品或价格。

目前的提醒在页面内显示，尚未发送邮件、聊天消息或手机推送。服务停止后定时监测也会停止；全天候监测需要部署到持续运行的机器。

## 数据与配置

- `data/prices.sqlite3`：商品配置和完整采集记录。备份此文件时应停止服务，或使用 SQLite 在线备份功能；运行中的 WAL 文件也可能包含最新记录。
- `SHOP_DB_PATH`：可选，指定数据库文件位置。
- `SHOP_PORT`：可选，默认 `8000`。
- `SHOP_ALLOWED_HOSTS`：可选，允许的 Host 名称（逗号分隔），默认仅 `localhost,127.0.0.1`。
- 每个商品最短检查间隔 15 分钟，默认 60 分钟；最多 100 个监测项，最多同时请求 4 个商品。页面展示每个来源最近 200 次记录。
- 修改来源链接、货币或价格选择器后，启用新的一组价格历史；之前的记录仍保存在数据库中。删除监测项会一并删除该项所有记录。
- 云环境的网络限制可能需要允许实际商品域名及其重定向域名。只添加需要的站点，不需要把密钥写入商品配置。

## 开发与验证

```bash
bash scripts/install.sh
.venv/bin/python -m unittest discover -s tests -v
```

测试覆盖价格提取、错误/歧义处理、请求安全、商品管理、历史持久化、目标价提醒和定时检查。测试中的报价为固定样例，不是实际商品的当前市场价格。启动后的 `/api/health` 会检查数据库可读性；机器可读的接口定义位于 `/openapi.json`。

`config/build-reference.json` 已录入用户截图中的 9800X3D 无独显主机配置及用户提供的 ¥8,239 折后参考报价。它不是实时采集记录，也没有被设为购买目标价。该商品链接仍待补充，监测列表保持为空；引用任务“监测双十一电脑配置价格”的其他内容暂未成功读取。

用户已要求主动检索各大平台。检索入口、公开候选及访问证据见 [整机检索记录](docs/market-search.md) 与 [配件比价记录](docs/component-search.md)。当前尚未取得相同配置的实时结算报价；公开候选没有导入监测清单。京东官方登录页已能访问，扫码资源仍受环境域名限制，所需域名见 [京东扫码登录进度](docs/jd-login.md)。
